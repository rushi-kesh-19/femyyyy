# FemEssence

FemEssence is a full-stack e-commerce web application focused on women's hygiene and wellness products.  
The platform provides users with a seamless shopping experience, including product browsing, authentication, cart management, and secure order workflows.

## Features

- User authentication & authorization
- Product catalog and filtering
- Shopping cart functionality
- Responsive frontend UI
- REST API integration
- MongoDB database integration
- Cloud deployment support using AWS EC2
- Full-stack MERN architecture

## Tech Stack

### Frontend
- React.js
- JavaScript (ES6+)
- CSS / Tailwind (if used)

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### Deployment
- AWS EC2
